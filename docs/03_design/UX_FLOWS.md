# UX Flows — FARIA

> **Status:** Not activated for V1.
>
> FARIA V1 uses the `prototype` base profile with the `ai-enabled` modifier (see `docs/PROJECT_INITIALIZATION.md`). > Activate this document once the dashboard or another surface grows cross-screen journeys complex enough to need explicit flow documentation beyond the feature spec.
